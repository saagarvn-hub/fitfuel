# FitFuel - Calorie Tracking & Fitness App

## Project Purpose
FitFuel is a comprehensive calorie tracking and fitness management web application that helps users monitor their daily food intake, track water consumption, log weight progress, and manage healthy recipes.

## Features
- User authentication (Login/Register)
- Meal diary with calorie tracking
- Recipe library with ratings
- Water intake tracker
- Weight progress tracker with charts
- Weekly meal planner
- Achievements & badges system
- Dark/Light mode toggle
- Profile management with photo upload
- Responsive design for all devices

## Technologies Used
- **Frontend:** HTML5, CSS3, JavaScript, Chart.js
- **Backend:** PHP 8.x
- **Database:** MySQL
- **Hosting:** InfinityFree (PHP)
- **Version Control:** Git & GitHub

## Setup Instructions
1. Clone the repository: `git clone https://github.com/saagarvn-hub/fitfuel.git`
2. Import `database.sql` into phpMyAdmin
3. Configure `includes/config.php` with your database credentials
4. Run on XAMPP/WAMP or deploy to a PHP hosting provider
